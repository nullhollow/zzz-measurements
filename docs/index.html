Source: modelmetrics.net · Zenless Zone Zero · Female Character Measurements. Schema v2 · data updated 2026-10-21.
Height: charted height may include ears, footwear and accessories. Stature comparisons use head height where the chart notes an appendage (Miyabi). Both values are shown in the table and the detail view.
Basis: every card, filter and ranking uses the standard model. A measured outfit is kept as its own record, shown in the detail view with its deltas; art-only outfits never touch a number.
Classes: waist (Cinched / Average / Fuller), hips (Compact / Average-width / Wide) and thighs (Slim / Average / Thick) are roster terciles of the raw circumference in cm. Build compares raw bust and hip percentiles; bust tier comes from bust minus under-bust. Thirteen agents (Rina, Yidhari, Caesar, Velina, Yanagi, Pulchra, Astra Yao, Sigrid, Jane Doe, Trigger, Cissia, Burnice, Orphie) are hand-pinned to Thick by curator read, so their detail view is marked “hand-pinned”. Shape (Hourglass / Balanced / Straight) uses waist ÷ hip.
Percentile bars: roster percentiles of the raw cm measurement; stature percentiles use head height. 0 = smallest, 100 = largest. Build is the bust percentile minus the hip percentile.
Confidence: charted no caveat, estimated a value is approximated, partial a value is missing. See the methodology.
Bust diff: recomputed as bust minus under-bust so it keeps one decimal (the sheet's own diff column is whole-number rounded).
Images: scale renders from modelmetrics.net; official art from the ZZZ Fandom wiki, © HoYoverse. Auto-comments are generated from the measurements; treat them as figure-chart commentary, not in-game canon.
Roster commentary stays in English; controls and labels are translated.
