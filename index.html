Source: modelmetrics.net · Zenless Zone Zero · Female Character Measurements.
Sheet caveats: heights come from official listings where available and usually include ears, footwear and accessories; all other measurements come from curves wrapped around the official 3D models, and some parts were removed for visibility, so treat every number as an estimate.
Classes: every class is a roster tercile of the raw measurement in cm. Waist (Cinched / Average / Fuller), hips (Compact / Average-width / Wide) and thighs (Slim / Average / Thick) use their own circumference; Build compares raw bust and hip percentiles; bust tier comes from bust minus under-bust. Thirteen agents (Rina, Yidhari, Caesar, Velina, Yanagi, Pulchra, Astra Yao, Sigrid, Jane Doe, Trigger, Cissia, Burnice, Orphie) are hand-pinned to Thick by curator read, so their detail view is marked “hand-pinned”. Shape (Hourglass / Balanced / Straight) is the one ratio-based class, using waist ÷ hip.
Percentile bars: the bust / waist / hips bars on each card (and all four in the detail view) are roster percentiles of the raw cm measurement. 0 = smallest in the roster, 100 = largest. Build (Top-heavy / Bottom-heavy / Balanced) is simply the bust percentile minus the hip percentile.
Auto-comments are generated from the measurements themselves; treat them as fun figure-chart commentary, not in-game canon.
Bust diff: recomputed as bust minus under-bust so it keeps one decimal (the sheet's own diff column is whole-number rounded). Bust sorting and the bust podium use it.
